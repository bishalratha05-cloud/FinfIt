ABOUT THE PROJECT

How FinfIt works

FinfIt is an educational document retrieval system built to demonstrate the core ideas of Web Search Mining.

1. Document processing

Text is extracted from supported files, converted to lowercase tokens, and common stop words are removed.

2. Inverted index

The index maps each term to the documents in which it appears, making candidate retrieval efficient.

3. Ranking

TF-IDF or BM25 assigns relevance scores and sorts matching documents.

4. Retrieval modes

Ranked retrieval, basic Boolean operators, and exact phrase matching are available.
